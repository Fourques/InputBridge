# 首次开源发布清单

v0.2.0a3 延续源码预览。可在 **Apple Silicon macOS + x86_64 Linux X11** 本地构建和试用。Windows、Wayland、Intel Mac 和 Linux 主控需分别完成实机验收。

| 项目 | 当前准备 | 放行条件 |
| --- | --- | --- |
| 文档与源码边界 | README、安装说明、离线打包入口及源码名单 | 每次发布按源码名单审阅归档，排除私钥、邀请、局域网地址、日志和个人启动脚本 |
| 第三方许可证 | [许可复核](Licensing.md)记录旧包的 Tika 问题。候选流程单独构建关闭内嵌 MIME 数据库的核心 Qt，已备官方许可文本、固定版本源码及 Deskflow 改版源码 | 确认原创补丁许可授权，按最终包复核 Qt 插件和其他实际依赖，并提供对应源码 |
| Mac 安装包 | 可在本地生成 ad-hoc 签名的应用及 ZIP | 用正式发行标识和 Developer ID 签名、公证、验证；从新账户或干净机器安装，验证 Gatekeeper、权限、退出和更新 |
| Linux 安装包 | X11 开发归档附带核心专用 Qt。界面由独立 Python 环境提供 | 选定发行版和 glibc 基线；用干净环境解包、建环境、启动并验证依赖与登录恢复，再决定是否补 .deb |
| 实机功能 | Mac 主控和 GNOME X11 客户端已验证双向文件移动、按住左键折返、文件剪贴板与滚轮 | 冻结发行包后重测配对、重名、快速折返、中文输入、触控板、休眠唤醒及长时间运行 |
| 安全与维护 | 文件通道有证书指纹校验和配对授权，缓存与私钥使用本地配置 | 复核文件路径和授权边界、权限与默认监听、缓存清理；明确安全报告和更新方式，梳理依赖版本、安全更新与故障回退 |

开发阶段可在本地打包和审阅，不需要将工作目录变成公开仓库。正式发布前，先按 `source-files.txt` 审阅源码，并对照二进制包实际包含的许可证和组件。此清单不表示许可兼容性已经审定或应用已经公证。
