# 滚轮手感
InputBridge 的「键鼠设置 → 鼠标滚轮」内提供 Mac 本机平滑、本机反向、跨屏反向和速度。两个方向的开关互相独立，步长和缓动时间在「高级」中。设置保存在主控 Mac 的本地配置中，不同步给对侧。所有调整默认关闭，现有配置迁移后保持原行为。Mos 仍运行时，键鼠核心启动和应用设置这两个时机会回避本机调整；退出 Mos 后可在设置里重新应用。

平滑只处理 Mac 主控抓取的离散鼠标滚轮。按住鼠标键选中文字时，滚轮继续使用当前屏幕的方向设置，并暂停平滑。触控板的连续滚动和惯性、系统生成的滚动、带修饰键的滚动保留原路径。鼠标切到对侧屏幕时丢弃本机缓动尾段，对侧按设置转发滚轮方向，并保留原有转发频率和滚动步幅。

已验收组合由 Mac 主控，GNOME / X11 Linux 作对侧。「跨屏反向 → 上下」可修正对侧的垂直滚动方向，和 Mac 本机方向独立。多设备布局中的每个远端各自方向，以及 Linux 作为本机鼠标主控时的平滑，尚未实现。

实机验收时，用同一只鼠标分别在 Mac 和 Linux 的浏览器做单格、快速连续、反向滚动，再用触控板重复，确认没有变化。滚动未结束时跨屏，检查两端都没有残留滚动。最后回归鼠标、中文输入和 Finder 到 Linux 的拖放。仅在通过后替换日常包并决定是否退出 Mos 自启。
